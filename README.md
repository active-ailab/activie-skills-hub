# Skills Hub · 本机脚本工作台

网页负责展示，Python 脚本直接读取本机目录。扫描不复制整个目录到浏览器，也不把文件发送到网上。说明文档按修改时间复用缓存，源文件及网页资源在查看时按需读取。

## 打开方式

完成下方首次安装后，本机将注册 `skills-hub://open` 协议。直接打开 `打开Skills.html`，或在在线入口点击“打开本机工作台”；浏览器提示时允许打开 Skills Hub。入口会启动本机 Python 服务并自动打开 http://127.0.0.1:8765 ，不显示终端窗口。已运行时复用服务。服务关闭后通过网页入口再次唤起，不需要 BAT，也未设置开机自启动。

在工作台填写本机目录（每行一个），点击“读取目录并学习”。支持 WSL 路径和 `D:\my-skills` 这样的 Windows 路径。下次打开先恢复上次整理结果，再核对目录变化。

首次安装（每台电脑各执行一次，支持 Windows + WSL）：

1. 在网页点击“首次使用：下载本机启动包”，解压到自己的 WSL 目录；也可复制本仓库源码。
2. 在 WSL 安装 Python 和 pip：`sudo apt-get install python3 python3-pip`。
3. 在解压出的 `skills-hub` 目录执行：

```sh
python3 launch.py install
```

安装后打开包内 `打开Skills.html`，或返回在线网页点击“打开本机工作台”，填写自己的 Skills 项目目录。

启动包包含网页、Python 本机服务和运行器，不包含任何人的扫描结果、账号、日志、虚拟环境或绝对项目路径。Python 后端按各项目的 `requirements.txt` / `pyproject.toml` 安装到独立环境；需要 Python 3.12 的项目由 uv 自动准备，不借用其他项目的库。Node 项目需先安装 Node 22+（包含 npm），首次启动自动执行 `npm ci`。

首次准备依赖需要访问 Python / npm 软件源。受网络限制时，可在安装/启动前设置 `SKILLS_HUB_PYPI_INDEX`、`SKILLS_HUB_NPM_REGISTRY` 指定自己的软件源；协议启动时，可将这两个同名配置写入本机 `.state/runtime-settings.json`（JSON 对象），无需修改源码。每位使用者需要拥有自己的 Skill 项目目录，启动包不分发扫描到的其他仓库源码。账号、设备和内网访问权限仍由每位使用者自行配置。普通在线静态网页不能直接运行访问本机文件或设备的后端，因此本机启动包是必要的。

注册仅作用于当前 Windows 用户。项目移动或更换 WSL 发行版后重新执行注册。普通网页不能绕过浏览器权限直接执行电脑上的脚本，所以第一次需要这一步；浏览器仍可能要求确认启动本机程序。

## 能力与数据

支持项目归类、搜索、中文名称、原文查看、学习笔记、源文件查看和下载，以及网页项目启动。网页项目的笔记按文档章节整理，不调用在线模型。非网页项目展示人工整理的中文使用指南，说明用途、场景、准备材料、使用步骤、预期输出、Agent 任务示例与能力边界；原始说明可在来源文件中核对。当前指南覆盖已整理的 29 个项目。指南按来源文档内容校验版本；来源变化时显示待复核，新项目未整理时明确提示，不自动编造命令或把 README 当成指南。指南基于项目说明，不代表已执行所有业务验证。

本机工作台绑定 127.0.0.1:8765，启动请求校验 Host、请求来源和会话令牌，只接受已收录的 HTML 页面。

点击“打开运行”会启动对应项目：静态网页使用独立端口提供原始资源，支持模块、跳转、联网和浏览器本地存储；已识别的 Python / Flask / Node 项目启动实际后端并等待就绪，服务已运行时复用。模板页打开后端路由，不直接展示模板源文件。运动记录生成器使用独立端口，避免与工作台的 8765 冲突。

支持当前收录的功能移植工作台、固件发布、分支对比、OTA、运动类型配置、运动记录生成、LTHR、Jira Auto 和 Active 开发工作台。首次启动按需准备依赖；Jira Auto 需要 Python 3.12，设备工作台需要 Node 22+。依赖下载、配置或启动失败时显示错误与 `.state/runtime/` 日志路径。实际联网能力仍取决于电脑网络、项目账号和配置。启动服务不会自动执行页面中的发布、刷机等业务操作。

`.state/local-workspace.json` 保存目录和整理结果；`.state/local-service.log` 为后台日志。学习状态保存在浏览器。清除本地资料不会修改源文件。`.venvs/` 保存按项目路径隔离的 Python 依赖环境，可在停止对应服务后删除并自动重建。

## 验证与发布

```sh
python3 -m unittest discover -s tests -v
node --test tests/browser-core.test.mjs
node build.mjs
```

`dist/` 包含在线唤起入口和自动生成的 `skills-hub-local.zip` 完整本机启动包，`.openai/hosting.json` 保留现有 Sites 身份。在线站点只提供启动入口，不存放用户文件。`local_server.py` 是本机读取服务，`launch.py` 负责协议安装与按需启动。


## 本地产物与提交

`.state/`（扫描结果、日志、下载的运行工具）、`.venvs/`（项目依赖环境）、`dist/`（构建包）和 Python/测试缓存均由 `.gitignore` 排除，不应提交。源码、测试、使用指南和 `.openai/hosting.json` 需要保留。

清理依赖环境前先停止对应项目服务；下次启动会重新准备依赖。清理扫描结果时保留 `local-workspace.json` 中的 `paths` 与 `mode`，并保留 `.state/runtime-settings.json` 的个人运行配置，重新读取目录即可恢复展示。发布包需要时运行 `node build.mjs` 重新生成。
